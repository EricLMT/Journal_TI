# journal_ti

Journal de TI est une app pour smartphone Android,
  

## Getting Started

Journal de TI,
  
Cette application permet de consigner des faits observés en lien avec des situations de harcèlement électromagnétique, sonore, et de gangstalking supposées.
Elle ne fait pas office de preuve, mais ce veut être une aide pour recenser des expériences perçues comme du harcèlement.
L'application utilise la géolocalisation approximative de votre téléphone.
Les données peuvent être enregistrées dans un fichier au format MS Excel©, et vous pouvez générer un rapport d'observation au format PDF exportable et partageable par e-mail ou autre.

L'application permet de créer et alimenter une base de données comportant les enregistrements de vos observations.
Lors de la création d'une observation, votre localisation approximative vous permettra de déterminer le lieu de votre observation.
Vous avez différents champs :\n
Date : La date ajoutée automatiquement, mais modifiable.
Heure : L'heure ajoutée automatiquement, mais modifiable.
Localisation approximative : La localisation automatique du lieu de l’observation.
Lieu de l'observation : Le lieu plus précis de votre observation.
Détail du lieu : Les détails éventuels sur le lieu.
Comportement observé : Les comportements observés.
Personnes impliquées : Les personnes impliquées dans l’observation.
Type d'interaction : Le type de interactions observée.
Lien d'interaction : Votre lien avec les personnes impliquées dans l'observation.
Récurrence : Si c'est un comportement ou une situation récurrente.
Impacts psychologiques : Les impacts psychologiques qu'a eu cette situation sur vous.
Impacts physiques : Les impacts physiques qu'a eu événement sur vous.
Témoins : Les personnes pouvant témoigner de cette situation.
Remarques : Vos remarques complémentaires.
Vous pourrez modifier ou effacer ultérieurement votre observation dans l'onglet Liste du formulaire.
